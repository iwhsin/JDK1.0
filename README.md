# Java Learning Journey

本项目记录了Java学习的完整过程，从基础概念到高级特性，系统化地整理Java开发知识体系。

## 📚 学习计划

### 基础部分
- Java语言基础
- 面向对象编程
- 集合框架
- 异常处理
- I/O操作

### 进阶部分
- 多线程与并发
- JVM原理与调优
- 设计模式
- 网络编程
- 数据库操作

### 学习 JDK 1.0 源码
JDK 1.0 是Java发展的起点，深入学习其源码有助于理解Java的核心设计思想和演进历程。通过分析早期版本的实现，我们能更好地把握Java语言的本质和发展方向。

**相关资源：**
- [JDK 1.0 完整源码](https://github.com/sunshower76/jdk1.0)
- [Java语言规范 (第一版)](https://www.oracle.com/java/technologies/java-se-first-edition-doc-archives.html)
- [JDK 1.0 官方文档](http://java.sun.com/JDK-1.0/)
