# JDK 1.0 源码阅读大纲

## 1. 前言

JDK 1.0 是 Java 开发工具包的第一个正式版本，发布于1996年1月23日。作为 Java 语言的早期实现，JDK 1.0 奠定了 Java 技术的基础架构，定义了核心 API 和语言特性。通过研读 JDK 1.0 的源码，我们可以深入了解 Java 的核心设计理念和实现机制，这对理解现代 Java 技术具有重要的参考价值。

本大纲旨在提供一个系统化的 JDK 1.0 源码学习路径，帮助开发者更有效地理解和掌握 Java 的基础知识。

## 2. JDK 1.0 整体结构

JDK 1.0 的目录结构如下：

```
 COPYRIGHT       - 版权声明文件
 README          - 说明文件
 bin/            - 可执行命令目录
 demo/           - 演示程序目录
 include/        - 本地方法头文件目录
 index.html      - 首页文档
 lib/            - 库文件目录
 src.zip         - 源代码压缩包
 src/            - 源代码目录
```

其中 `src/` 目录是我们学习的重点，包含了 JDK 1.0 的所有源代码，主要分为两个部分：

- `java/` - 标准 Java API 包
- `sun/` - Sun 公司提供的扩展包

## 3. 核心包结构分析

### 3.1 java.lang 包

`java.lang` 包是 Java 语言的核心，提供了最基本的类，被所有 Java 程序隐式导入。

**主要类文件：**
- `Object.java` - 所有类的基类
- `Class.java` - 类的元数据
- `System.java` - 系统相关功能
- `Thread.java` - 线程实现
- `ThreadGroup.java` - 线程组管理
- `String.java` - 字符串实现
- `StringBuffer.java` - 可变字符串
- `Math.java` - 数学运算
- `Throwable.java` - 异常体系的根
- 包装类：`Boolean.java`, `Character.java`, `Integer.java`, `Long.java`, `Float.java`, `Double.java`
- 异常类：多种异常实现类

**学习要点：**
- Java 对象模型设计
- 基本类型的包装机制
- 字符串设计与实现
- 线程模型基础
- 异常体系设计

### 3.2 java.io 包

`java.io` 包提供了输入输出系统，是 Java 程序与外部世界交互的基础。

**主要类文件：**
- `File.java` - 文件操作
- `InputStream.java` / `OutputStream.java` - 输入输出流基类
- `FileInputStream.java` / `FileOutputStream.java` - 文件流
- `BufferedInputStream.java` / `BufferedOutputStream.java` - 缓冲流
- `DataInputStream.java` / `DataOutputStream.java` - 数据处理流
- `PrintStream.java` - 打印流
- `RandomAccessFile.java` - 随机访问文件

**学习要点：**
- 装饰器模式在 IO 流中的应用
- 字节流与字符流的设计
- 缓冲机制实现
- 文件系统接口设计

### 3.3 java.util 包

`java.util` 包提供了各种实用工具类，包括集合类、日期时间处理等。

**主要类文件：**
- `Vector.java` - 动态数组实现
- `Hashtable.java` - 哈希表实现
- `Stack.java` - 栈实现
- `Dictionary.java` - 字典抽象类
- `Date.java` - 日期时间处理
- `Random.java` - 随机数生成
- `Properties.java` - 属性文件处理
- `Enumeration.java` - 枚举接口
- `StringTokenizer.java` - 字符串分词器

**学习要点：**
- 集合框架早期设计
- 哈希表实现原理
- 属性管理机制
- 迭代器模式应用

### 3.4 java.net 包

`java.net` 包提供了网络编程支持，实现了各种网络协议的 Java 接口。

**主要类文件：**
- `Socket.java` - 客户端套接字
- `ServerSocket.java` - 服务器套接字
- `URL.java` - URL 解析与处理
- `URLConnection.java` - URL 连接
- `InetAddress.java` - IP 地址表示
- `DatagramSocket.java` / `DatagramPacket.java` - UDP 实现

**学习要点：**
- 网络编程模型
- Socket 通信实现
- URL 处理机制
- 网络异常处理

### 3.5 java.awt 包

`java.awt` 包是 Abstract Window Toolkit 的缩写，提供了基本的图形用户界面组件。

**主要类文件：**
- `Component.java` - 组件基类
- `Container.java` - 容器基类
- `Window.java` / `Frame.java` / `Dialog.java` - 窗口实现
- `Panel.java` - 面板实现
- 基础组件：`Button.java`, `Label.java`, `TextField.java`, `TextArea.java`, `Checkbox.java`, `Choice.java`, `List.java`
- 布局管理：`LayoutManager.java`, `FlowLayout.java`, `BorderLayout.java`, `GridLayout.java`, `GridBagLayout.java`
- 图形绘制：`Graphics.java`, `Color.java`, `Font.java`
- 事件模型：`Event.java`

**学习要点：**
- 组件继承体系
- 早期 AWT 事件模型
- 布局管理机制
- 绘图 API 设计

### 3.6 java.applet 包

`java.applet` 包提供了 Applet 应用的支持，Applet 是早期网页中嵌入的 Java 小程序。

**主要类文件：**
- `Applet.java` - Applet 基类
- `AppletContext.java` - Applet 上下文
- `AppletStub.java` - Applet 存根接口
- `AudioClip.java` - 音频剪辑接口

**学习要点：**
- Applet 生命周期
- 浏览器与 Applet 交互机制
- Applet 安全模型

### 3.7 sun.tools 包

`sun.tools` 包包含了 JDK 工具的实现，此处仅包含调试工具部分。

**主要类文件：**
- `ttydebug/TTY.java` - 命令行调试器

**学习要点：**
- 早期 Java 调试器实现
- 调试 API 设计

## 4. 学习路径建议

为了系统地学习 JDK 1.0 源码，建议按照以下顺序进行：

1. **基础阶段**: 先学习 `java.lang` 包，掌握 Java 的核心类设计
   - 重点关注 `Object`, `String`, `Thread` 等基础类

2. **IO 阶段**: 学习 `java.io` 包，了解 Java 的输入输出系统
   - 重点研究流的层次结构和设计模式

3. **工具阶段**: 学习 `java.util` 包，理解集合框架和实用工具类
   - 重点分析 `Vector`, `Hashtable` 等数据结构实现

4. **网络阶段**: 学习 `java.net` 包，掌握网络编程基础
   - 重点理解 Socket 编程和 URL 处理

5. **GUI 阶段**: 学习 `java.awt` 和 `java.applet` 包，了解图形界面编程
   - 研究组件体系和事件处理机制

## 5. 历史背景与演进

在学习 JDK 1.0 源码时，值得注意的是：

- JDK 1.0 是 Java 的初始版本，很多设计在后续版本中有重大变化
- 集合框架在 JDK 1.2 中进行了重大改革，增加了 `Collections` 和 `Map` 等接口
- AWT 事件模型在 JDK 1.1 中被委托事件模型取代
- 异常处理机制在后续版本中增加了 `try-with-resources` 等特性
- 字符串处理在后续版本中增加了 `StringBuilder` 等新类
- 线程模型在后续版本中增加了并发包、同步工具等扩展
